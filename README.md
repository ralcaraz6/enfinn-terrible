# ENFINN TERRIBLE

Official website for ENFINN TERRIBLE.

Static site (HTML/CSS/JS), no build step. Layout modelled on the classic music-artist
site structure: sticky nav, full-bleed hero, store/format grid, music, news, newsletter
signup and footer with social links.

All content is placeholder and meant to be replaced.

## Structure

| File | Purpose |
| --- | --- |
| `index.html` | Page markup and all sections |
| `styles.css` | Styling (monochrome artist theme) |
| `script.js` | Mobile nav toggle |

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```
